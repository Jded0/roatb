# موعدي

موقع عربي لمتابعة مواعيد الرواتب والدعم والتقويم الدراسي، مع تطبيق أندرويد يعمل دون اتصال.

## تثبيت تطبيق أندرويد

1. افتح صفحة [أحدث إصدار أندرويد](https://github.com/Jded0/roatb/releases/tag/android-latest).
2. نزّل `app-debug.apk` إلى هاتف أندرويد وافتح الملف للتثبيت.
3. إذا طلب أندرويد ذلك، اسمح لمتصفح الملفات بتثبيت التطبيقات من مصادر خارجية.

هذا إصدار تجريبي موقّع بمفتاح التصحيح، وغير مخصص للنشر في المتاجر. يعرض التطبيق ملفات الموقع المضمّنة داخله، لذلك يعمل دون اتصال بالإنترنت.
